## 第一部分：文档概述

按个人开发者列出可操作的 CLI 命令与桌面菜单/功能点，作为实现与验收依据。

### 1.1 背景与目标

把 AA 功能子模块展开为开发者可执行的操作：命令行入口与桌面三视图（身份 / 仓库审计 / 凭据）及页头能力。

### 1.2 文档定位

| 定位 | 说明 |
|------|------|
| 本文档做什么 | 按用户类型分章，列出每个用户可操作的菜单项和功能点描述，作为功能开发和权限配置的依据 |
| 本文档不做什么 | 不涉及技术实现方案、不涉及数据库设计、不涉及接口定义和系统架构 |

### 1.3 范围

| 范围 | 说明 |
|------|------|
| 业务域 | Git 多身份管理 |
| 用户类型 | 个人开发者 |

## 第二部分：功能清单

> 本章按用户类型分章，每章按应用域→功能模块→功能子模块逐层描述菜单和功能点。

### 本清单概览

仅一种用户。核心操作在 CLI 全覆盖；桌面端覆盖档案、目录绑定、扫描处置、历史审计、体检、语言与更新；shell 补全仅 CLI；英文 README 为文档产物不进菜单。

## 2.1 个人开发者

**用户类型概述**：本机单人使用 gitid CLI 与桌面端，管理 2~5 套身份，把目录树绑到默认身份，审计并处置仓库配置，核验历史作者，体检环境。

#### 2.1.1 核心业务域

**应用域概述**：档案、应用、目录绑定、扫描、处置、历史审计是日常主路径。

##### 2.1.1.1 身份档案管理

**功能说明**：维护本机身份档案，含签名格式与从扫描收编。

###### 新建与更新身份

**功能说明**：按 id 创建或覆盖档案。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| gitid add | 新增/更新档案；`--format openpgp\|ssh\|x509` 声明签名格式 | 新建与更新身份 | 与 `--signingkey` / `--gpgsign` 并列 |
| 身份管理 / 新增身份 | 弹窗填写 id/name/email/签名键/签名开关/签名格式/重写/选择器 | 新建与更新身份 | 桌面 |
| 身份管理 / 编辑 | 同弹窗更新已有档案（id 不可改） | 新建与更新身份 | 桌面 |

###### 导入全局配置为档案

**功能说明**：从全局 git 收编一条档案。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| gitid import [--as] | 导入当前全局 name/email/签名 | 导入全局配置为档案 | 已有 |
| 身份管理 / 导入当前全局配置 | 同上 | 导入全局配置为档案 | 桌面 |

###### 收编扫描手配为档案

**功能说明**：把 ⚠ 手配收进档案库。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| gitid import --scan [目录] | 扫描后收编 unknown 行；已命中跳过 | 收编扫描手配为档案 | `--as` 仅单条时指定 id |
| 仓库审计 / 收编手配 | 对当前结果中 ⚠ 行确认后写入档案 | 收编扫描手配为档案 | 桌面 |

###### 删除身份

**功能说明**：删除档案，不改 git。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| gitid remove | 按 id 删除档案；有绑定则先回收 include 片段 | 删除身份 | 不改 global/local 已应用键 |
| 身份管理 / 删除 | 确认后删除（含回收绑定） | 删除身份 | 桌面 |

###### 查阅身份列表

**功能说明**：列出档案与匹配标记。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| gitid list | 表格列出；★ 全局 ◆ 本地；展示 gitdirs | 查阅身份列表 | |
| gitid current | 展示生效身份；来源 local / includeIf / global（--show-origin） | 查阅身份列表 | 沿用命令，增强来源 |
| 身份管理 / 表格 | 展示档案、全局标记与已绑定目录（可点除） | 查阅身份列表 | 桌面 |

###### 声明签名格式

**功能说明**：为档案设置或清空格式。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| gitid add --format | 写入 gpg.format；省略则档案不带格式 | 声明签名格式 | 应用时未带则 unset |
| 身份表单 / 签名格式 | 下拉 openpgp/ssh/x509/空 | 声明签名格式 | 桌面 |
